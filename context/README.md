# spike-html-packages-foundation

spike-html-packages-foundation is the foundation layer of
[spike-html-packages](https://github.com/JaimeStill/spike-html-packages): the baseline stylesheets, the tool sheets, the DOM helpers, the registry and keys family, and the formatter declarations. It is
released by tag and built on by the layers above it, as the Go workspace's repositories are.
This context records only working knowledge the code and the README do not express.
