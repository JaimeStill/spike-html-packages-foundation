## [v0.1.0] - 2026-10-23

### Added

- The foundation layer, moved from spike-html-packages (7fb31a8): the baseline stylesheets, the
  meta, structure, and utilities tool sheets, and the `page.css` entry; the DOM helpers; the
  registry and keys family, its help dialog loaded lazily; and the formatter declarations.
- The ambient `*.css` declaration for CSS module scripts, as the `./css` types subpath.
- The release by tag: `v<version>`, whose tree is the pack, with the tarball on its GitHub
  release.
